# Visión del Proyecto — FireLab

## Descripción general

FireLab es un proyecto cuya visión a largo plazo es desarrollar un videojuego que evolucione hasta convertirse en un simulador avanzado de incendios y un laboratorio virtual para diseñar y probar nuevos agentes extintores.

El objetivo final no es únicamente crear un videojuego, sino construir una plataforma que sirva para:

- Entretenimiento
- Educación
- Divulgación científica
- Investigación
- Generación de ideas para combatir incendios
- Recaudación de fondos para personas afectadas por incendios e investigaciones reales

El proyecto busca tener potencial comercial para financiar su propio desarrollo.

## Filosofía del proyecto

No se busca un simulador perfecto desde el principio. La idea es comenzar con un juego divertido y convertirlo gradualmente en un simulador cada vez más realista.

**Evolución planeada:**

1. **Videojuego**
2. **Laboratorio** — los jugadores diseñan agentes extintores
3. **Simulador físico** más realista
4. **Plataforma educativa**
5. **Herramienta de investigación** inspirada en ciencia real

## Idea principal

Los grandes incendios forestales modernos no son simplemente "llamas grandes". Son sistemas complejos donde intervienen:

- Viento
- Temperatura
- Humedad
- Tipo de vegetación
- Pendiente
- Combustible
- Radiación térmica
- Propagación por brasas

FireLab busca simular todos esos factores con el tiempo.

## Hipótesis del proyecto

La mayor innovación futura contra incendios probablemente no será una molécula milagrosa, sino una combinación de:

- Nuevos materiales
- Mejores estrategias
- IA
- Robótica
- Drones
- Química
- Simulación

FireLab debe permitir experimentar con esas ideas.

## Concepto de "Laboratorio"

El jugador podrá crear nuevos agentes extintores modificando propiedades como:

- Capacidad de absorción de calor
- Viscosidad
- Adherencia
- Densidad
- Biodegradabilidad
- Costo
- Tiempo de evaporación
- Toxicidad
- Estabilidad
- Capacidad para inhibir radicales libres
- Formación de espuma
- Capacidad de enfriamiento

> No se pretende afirmar que una mezcla virtual funcionará en la realidad. Es un laboratorio de hipótesis.

## Idea científica conceptual: sistema multicapa

Concepto de una "microgota inteligente" con capas de:

1. Agua
2. Hidrogel biodegradable
3. Material endotérmico
4. Inhibidor de radicales libres

Que se desplazaría con las corrientes del incendio, se adheriría al combustible, absorbería calor, formaría espuma y reduciría reencendidos.

Esta idea es **puramente conceptual** y sirve como inspiración para mecánicas del juego, no como propuesta científica validada.

## Idea "Proyecto Hydra"

Un enfoque alternativo: no intentar apagar únicamente la llama, sino impedir que el incendio se propague.

- Proteger el combustible antes de que arda
- Crear barreras temporales
- Usar drones
- Detectar el incendio muy temprano
- Atacar durante los primeros minutos

## Filosofía de desarrollo

Motor modular, no un juego monolítico. Cada sistema es independiente y puede mejorarse sin reescribir el proyecto completo:

- Sistema de fuego
- Sistema climático
- Sistema de vegetación
- Sistema de terreno
- Sistema de humo
- Sistema de agua
- Sistema químico
- Sistema de drones
- Sistema económico

## Primer objetivo jugable

Escenario mínimo donde:

- Un árbol pueda incendiarse
- El fuego se propague
- Exista viento
- El jugador pueda apagarlo con agua

Nada más por ahora — el resto llega después.

## Visión a largo plazo

FireLab aspira a convertirse en un referente sobre simulación de incendios, evolucionando hasta incluir:

- Simulación física avanzada
- IA
- Campañas educativas
- Desafíos científicos
- Colaboración con universidades
- Eventos comunitarios
- Recaudación transparente para víctimas de incendios y apoyo a investigaciones reales

> Nunca se afirmará que las formulaciones virtuales funcionan en el mundo real sin validación experimental. El juego sirve para aprender, experimentar e inspirar nuevas ideas.
